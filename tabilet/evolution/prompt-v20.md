# Explicit local optional-script denial policy

Approved direction: one immutable local HTTPS-origin rule may keep
non-navigation GET/Script requests blocked without ending authenticated authoring.
This is a denial policy, never an origin permission. Defaults and other
violations remain fatal. It is absent from page-controlled protocol messages,
portable profiles and registration. Preserve budgets, first failure, cancellation,
redirect/OOPIF containment and exact qualified-byte adoption.

A14.5 coordinates with W8M W13.1l. Local containment and full integration
verification remain mandatory; this direction alone proves no live acceptance.
