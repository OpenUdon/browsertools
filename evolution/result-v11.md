# Result V11 - One Process Owns the Authenticated Author Session

Browsertools A03 is now executable. `author-session chromium` owns one headed,
non-persistent Chromium context and accepts only closed, bounded NDJSON. The
human types credentials and OTP values directly into focused browser fields;
push MFA is a locator-free checkpoint. Candidate IDs—not caller selectors,
coordinates, scripts, or Playwright objects—address every portable action.

Same-origin GET navigation is automatic only inside an explicit action window.
Clicks always require approval; a link to a new exact origin requires an origin
approval followed by a separate click approval, and POST authority is finite
and scoped to that click. Unexpected navigation, unsupported surfaces,
ambiguity, denial, protocol failure, browser failure, or teardown failure
destroys the context and produces no artifact.

The implementation also stages E05 reduced observations and P04 deterministic
candidate synthesis. Those lanes record their own promotion and qualification
decisions separately; A03 establishes only the live-context ownership and
authority boundary.
